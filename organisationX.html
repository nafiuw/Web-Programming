The Challenge We're Solving

A snapshot of the structural gaps in programming education across schools, colleges, and universities in Bangladesh.

01
Exam oriented mindset: Students study only to pass exams, not to solve real problems.
02
Lack of structure: CS fundamentals are largely absent from curriculum. Non CS guys can't even get that.
03
CP is inaccessible: Competitive Programming remains out of reach for most, specially young school (1-12) students.
04
No mentorship: Talented students lack structured guidance and roadmaps.
05
AI is transforming IT: Analytical thinking matters more than ever. Students must learn to think, not just generate code.
The Reality

Most institutions teach just enough to pass exams. Students memorize syntax instead of learning algorithmic thinking, leaving them unprepared for real world software engineering and highly dependent on AI tools.

Phase 01
07 / 25

Foundation Programming

Building the mental models of computation, logic, and structured problem-solving before writing serious code.

Core Topics
Variables & Data Types Operators & Expressions Conditional Logic Loops (for, while, do-while) Functions & Recursion Arrays (1D, 2D) Strings & Character Arrays Pointers (intro) Structs Time & Space Complexity Big-O Notation Debugging & Testing Git & GitHub Intro
Phase 02
08 / 25

Intermediate DSA & STL

Transitioning to C++ and the Standard Template Library, then mastering the core data structures that underpin all of competitive programming.

Core Topics
C++ Syntax & Memory Model STL Vectors STL Maps & Sets STL Stacks & Queues STL Priority Queue Iterators & Algorithms Linked Lists (Singly, Doubly) Stacks (Array & List impl.) Queues & Circular Queues Hash Tables & Unordered Map Binary Trees Binary Search Trees Heaps Trie Disjoint Set Union (DSU) Bit Manipulation
Phase 03
09 / 25

Advanced Algorithms

The phase that separates problem-solvers from coders. Every major algorithmic paradigm, taught with proof, implementation, and contest application.

Core Topics
Binary Search & Ternary Search Two Pointers & Sliding Window Prefix Sums & Difference Arrays Greedy Algorithms Divide & Conquer Recursion & Backtracking Dynamic Programming (1D, 2D) DP on Trees DP on Bitmask Digit DP Graph Traversal (BFS, DFS) Shortest Path (Dijkstra, Bellman-Ford) Floyd-Warshall Minimum Spanning Tree (Kruskal, Prim) Topological Sort Strongly Connected Components Number Theory (Sieve, Modular, GCD) Segment Tree Fenwick Tree (BIT) Sparse Table String Algorithms (KMP, Z, Rabin-Karp) Hashing LCA & Binary Lifting PBDS (Policy-Based DS)
Phase 04
10 / 25

Competitive Programming

Where mastery becomes strategy. Contest psychology, team communication, advanced topics, and preparation for the world's toughest programming competitions.

Core Topics
Heavy-Light Decomposition Centroid Decomposition Persistent Data Structures FFT & NTT Aho-Corasick Suffix Array & Suffix Tree Game Theory (Nim, Sprague-Grundy) Combinatorics & Generating Functions Linear Algebra & Matrix Exponentiation Probability & Expected Value Geometry (Convex Hull, Sweep Line) Mo's Algorithm Meet in the Middle Team Strategy & Communication Contest Psychology ICPC Regionals Mock Contests IOI-style Problems BdOI Past Paper Drills

Financial Aid Program
22 / 25

Talent doesn't choose where it's born

No deserving student should stop learning due to financial limitations. Period.

Our Pledge

If a student has the will to learn, OrganizationX has the responsibility to remove every financial barrier in their path. A merit and need based financial aid program ensures deserving students participate without financial barriers.

Full Fee Waivers: 100% waiver on any membership or program fee for qualifying students.
Sponsored Memberships: Donors and sponsors can directly fund individual student memberships.
Contest Registration Support: ICPC, IOI, BdOI, and other contest registration fees covered for qualifying members.
Small Fee Note: If funds are insufficient, a small optional fee may be introduced, but it is always waivable.
